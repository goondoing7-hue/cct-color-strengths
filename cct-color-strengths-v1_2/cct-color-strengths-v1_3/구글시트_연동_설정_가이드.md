# CCT 검사 결과 → 구글 시트 + 드라이브 자동 수집 설정 가이드

이 앱은 서버가 없는 정적 사이트라서, "누가 검사를 완료했는지"와 "어떤 결과가 나왔는지 · 상세 PDF"까지
자동으로 모으려면 구글 시트 + Google Apps Script를 연동해야 합니다. 한 번만 설정해두면 이후로는 신경 쓸
일 없이, 검사가 끝날 때마다 결과가 시트에 한 줄씩 자동으로 쌓이고, 상세 결과 PDF도 구글 드라이브에
자동 저장되어 그 파일 링크가 같은 줄에 함께 기록됩니다.

이 연동은 **v1(자가 다운로드) / v2(센터 방문 안내) 두 버전 모두에서 동일하게 동작**합니다. v2는 사용자
본인에게는 PDF 다운로드를 제공하지 않지만, 관리자(본인)에게는 v1과 동일하게 자동으로 기록·저장됩니다.

설정에는 구글 계정(무료)만 있으면 되고, 비용은 들지 않습니다. 아래 순서대로 따라 하시면 10분 이내로 끝납니다.

## 1. 구글 시트 만들기

1. [sheets.google.com](https://sheets.google.com)에서 새 스프레드시트를 만듭니다.
2. 이름을 알아보기 쉽게 정합니다. 예: `CCT 검사 응답`

## 2. Apps Script 붙여넣기

1. 방금 만든 시트에서 상단 메뉴 **확장 프로그램 → Apps Script**를 클릭합니다.
2. 기본으로 열려 있는 `Code.gs` 파일의 내용을 전부 지우고, 이 앱과 함께 전달된
   `google-apps-script.gs` 파일의 내용을 그대로 붙여넣습니다.
3. 저장 아이콘(💾)을 눌러 저장합니다. (프로젝트 이름은 아무거나 상관없습니다.)

## 3. 웹 앱으로 배포하기

1. Apps Script 편집기 오른쪽 위의 **배포 → 새 배포**를 클릭합니다.
2. 배포 유형에서 톱니바퀴(⚙️)를 눌러 **웹 앱**을 선택합니다.
3. 설정을 다음과 같이 지정합니다.
   - **다음 사용자로 실행**: 나 (본인 계정)
   - **액세스 권한이 있는 사용자**: 모든 사용자 (Anyone)

   > 이 설정은 "누구나 이 검사 앱에서 결과를 제출할 수 있게" 열어주는 것이지, 시트나 드라이브 파일 자체를
   > 공개하는 것이 아닙니다. 시트 내용과 저장된 PDF는 여전히 본인 계정에만 보입니다.
4. **배포**를 클릭하면 구글 계정 권한 승인 화면이 나옵니다. 본인 계정으로 승인해주세요.
   이번에는 시트 접근 권한뿐 아니라 **드라이브 접근 권한**도 함께 요청됩니다 (PDF 파일을 드라이브에
   저장하기 위해 필요합니다). 본인 소유의 시트·드라이브에 대한 권한이라 안전합니다.
5. 배포가 끝나면 **웹 앱 URL**이 표시됩니다. 이 URL을 복사해두세요.
   형태 예시: `https://script.google.com/macros/s/AKfycb.../exec`

   > 이미 예전에 배포해두신 분들은 코드만 새로 붙여넣었다면 **배포 → 배포 관리 → 편집(연필 아이콘) →
   > 새 버전** 순서로 "새 버전"으로 다시 배포해야 이번 PDF 저장 기능이 반영됩니다. URL은 그대로 유지됩니다.

## 4. 앱에 URL 연결하기

1. 압축을 푼 앱 폴더에서 `js/app.js` 파일을 텍스트 편집기로 엽니다.
2. 아래 줄을 찾습니다.
   ```js
   const GS_WEBHOOK_URL = "";
   ```
3. 따옴표 사이에 방금 복사한 웹 앱 URL을 붙여넣습니다.
   ```js
   const GS_WEBHOOK_URL = "https://script.google.com/macros/s/AKfycb.../exec";
   ```
   v1, v2 두 버전 모두 각자의 `js/app.js`에 **같은 URL**을 넣으면, 두 버전의 응답이 같은 시트에 함께
   쌓입니다 (버전 열로 구분됩니다).
4. 저장한 뒤, 폴더 전체를 다시 압축해서(또는 수정된 `app.js` 파일만) 각 버전의 Netlify Deploys 탭에
   드래그 앤 드롭으로 재배포합니다.

## 5. 확인하기

1. 배포된 사이트에서 실제로 검사를 한 번 완료해봅니다.
2. 구글 시트로 돌아가면 `응답`이라는 시트가 자동으로 생기고, 아래와 같은 열로 결과가 한 줄 추가됩니다.

   | 제출시각 | 이름 | 버전 | TOP1 | TOP2 | TOP3 | 보완 컬러 | 상세 PDF | 빨강 | ... | 터콰이즈 |
   |---|---|---|---|---|---|---|---|---|---|---|

3. "상세 PDF" 열의 링크를 클릭하면 구글 드라이브에 저장된 그 사람의 상세 결과 PDF가 바로 열립니다.
   (드라이브의 **"CCT 검사 결과 PDF"** 폴더에도 전체 목록이 쌓입니다.)

## 참고 사항

- **무엇이 기록되나요?**: 검사를 실제로 끝까지 완료한 사람만 기록됩니다. 이름, 완료 시각, 사용한 앱
  버전(v1/v2), TOP1~3 컬러, 보완 컬러, 13개 컬러 전체 점수, 그리고 **상세 결과 PDF 파일 링크**까지
  한 줄에 저장됩니다. (중간에 그만둔 경우는 기록되지 않습니다.)
- **v1과 v2의 차이**: 검사 진행과 결과 화면은 동일합니다. 차이는 딱 하나, 상세 PDF를 v1은 검사 직후
  본인이 바로 다운로드할 수 있고, v2는 본인 다운로드 없이 "센터 방문 시 제공" 안내와 방문 지점(네이버
  지도) 링크만 보여줍니다. 관리자 쪽 기록(시트+드라이브 PDF)은 두 버전 모두 동일하게 자동 저장됩니다.
- **URL을 비워두면?**: `GS_WEBHOOK_URL`을 빈 문자열(`""`)로 두면 아무 데도 전송되지 않고 PDF도
  저장되지 않습니다. 즉, 이 연동은 완전히 선택 사항이며 기본값은 "수집 안 함"입니다.
- **개인정보**: 사용자가 직접 입력한 이름(또는 별명)과 상세 결과 PDF가 시트/드라이브에 저장됩니다.
  실명 수집이 부담스러우시면 안내 문구에 "별명으로 입력해달라"는 문구를 추가하는 것도 방법입니다.
- **중복 방지**: 같은 검사 1회당 결과·PDF는 정확히 한 줄/한 파일만 기록되도록 처리했습니다 (재검사
  시에는 새로운 한 줄과 새 PDF 파일이 추가됩니다).
- **전송 용량**: PDF가 함께 전송되다 보니 예전보다 전송 데이터가 조금 커집니다(리포트 1건당 약
  1~2MB 수준). 검사 완료 후 결과 화면이 뜨는 즉시 백그라운드에서 조용히 전송되며, 사용자의 화면
  이용에는 영향이 없습니다.
